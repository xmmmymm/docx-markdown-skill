# 高中化学试题 docx→Markdown 转换规范（优化版）

> 本版基于「专题06 铁、铝及其化合物」转换实践中暴露的 12 类问题，对原提示词进行补充与强化。新专题转换时直接沿用本规范。

## 〇 本轮问题与经验总结

### A. 脚本实现陷阱（导致静默失败/结构破坏）
1. **make_skeleton 死循环**：`while i < len(lines)` 主循环中，表格分支、选项分支、`if not m: continue` 三处 `continue` 均未步进 `i`，导致进程死循环后被超时终止，表现为「exit=1、stdout/stderr 全空」。**铁律：while 循环内任何 continue 前必须保证 i 已步进**；表格分支消费完 `</TBL>` 后须 `i += 1` 跳过结束标记。
2. **块结构被打散**：表格行、引用块行若逐条 append 到 out 再用 `'\n\n'.join`，会在行间插入空行，破坏表格连续性与引用块完整性。**正确做法：out 为「块列表」，每个逻辑块（段落/整张表/整个引用块）是一个字符串，块内行用 `'\n'` join，块间用 `'\n\n'` join**。
3. **flush_quote 追加 None**：`out.append(x if False else None)` 会让 join 抛 TypeError；调试时务必让 traceback 落盘（`python script.py 2>err.log`）。

### B. 内容校验盲区（导致化学性错误漏网）
4. **下标排位错误**：`[Al(OH)]₄⁻` 实为 MTEF 树中下标挂在 fence 外侧，化学正确应为 `[Al(OH)₄]⁻`。仅看预览图会「忠实照抄」错误排式。**须结合【答案】/【分析】及同文同物质正确排式（如 `Na[Al(OH)₄]`）互证后修正，并记入修正清单**。
5. **SUB/SUP 映射不全**：源文档用全角 `—` 作上标负号、全角 `＋` 作上标正号，初版 SUP 字典未覆盖，被原样残留为 `OH—`、`[Al(OH)₄]—`。**转写前先 grep 统计 content_stream 中全部 `[[SUB:…]]`/`[[SUP:…]]` 内容，对字典未覆盖字符逐一定义映射**（`—`→⁻、`＋`→⁺、`－`→⁻ 等）。
6. **守恒校验器 bug**：自写校验器未把系数乘进电荷、未解析 Unicode 上标数字（²³），产生大量假阳性。**须提供标准实现：分子式前缀系数 ×（电荷值）；上标 ⁰¹²³⁴⁵⁶⁷⁸⁹ 先转 ASCII 再解析**；对方程式按 `+` 切项时先 strip 空格，避免被源文 `+ ` 空格切成碎片误判。
7. **全角符号混入公式**：公式内 `＋`（2 处）、`＝`（4 处）需统一半角；但正文中文全角括号 `（）` 须保留。**规则：仅在公式上下文（化学式/方程式）内统一，正文标点不动**。

### C. 排版规则模糊（导致空格处理两难）
8. **空格三态冲突**：填空多空格（保留）、单位空格 `0.5 mol/L`（保留）、公式符号旁残余单空格 `= 5.2`/`+ 64(`/`Cu = 2Fe`（清除）三者形态相近。**清理时须用「多空格豁免 + 单位上下文豁免」的双正则，且填空框转空格时用双空格以与单空格残余区分**。
9. **题号分段重启**：基础题 1–26、提升题 1–11，总数 37；曾误计为 25+12。**计数以【答案】数为准，题号分段重启属正常**。
10. **选项在表格之后**：第 13 题「题干→表格→选项」结构，表格分支曾把 `in_q` 重置为 False，导致后续选项未进引用块。**表格分支不得改 in_q 状态**。

### D. 环境与资源
11. **游离媒体文件**：`image201.png` 存在于 media/ 但 document.xml.rels 未引用（孤儿）。**复制图前须校验每个 media 文件是否被正文 DRAW 引用，未引用者不复制并记入说明**。
12. **终端 GBK 乱码**：bash 管道输出中文乱码曾误导判断（误以为 skeleton 出错）。**涉及中文内容判定时改用 Read 工具或 Python repr，不以终端 grep 输出为准**。

## 一 总体要求

1. **样板基线**：先读 `01 钠及其化合物/专题08 钠及其化合物（解析版）.md` 确定版式（标题单空格、选项引用块、`=(点燃)=`、〔图：…〕、管状表）。
2. **公式/符号图**：逐张识别并结合上下文互证；**程序化还原优先于视觉识别**（MathType OLE 含 MTEF 二进制源时直接解析）。
3. **只提取正文**；不提取页眉页脚、超链接锚点。
4. **错误处理分级**：
   - 排版错误（下标排位、全角符号、残余空格、Tab 分隔）→ **修正并列出**；
   - 字样错误（KC1、NaC1、HCI、1₂、—定条件等源文笔误）→ **原样保留**；
   - 下标损坏 → **结合【答案】/【分析】及同文同物质正确排式反推修正**。

## 二 图片处理

1. **符号/公式图**（OLE 公式、上下标图）→ 转文字，不插图。
2. **非符号图**（装置/曲线/流程/关系/表格截图）→ 保留，按原文件名复制到 `images/`，md 用 `![](images/原文件名)` 紧跟 `〔图：描述〕`。
3. **空白/装饰图** → 删除并记入说明。
4. **填空方框图**（系数填空 □/方框）→ 转写为**双空格**（与单空格残余区分），不插图。
5. **同图多处**：识别一次，每处正确呈现；同名哈希比对跳过重复复制。
6. **表格内图**：同样处理，图描述写在单元格内。
7. **游离媒体**：复制前校验 media 文件是否被正文 DRAW 引用，未引用者不复制并记录。

## 三 转写规范

- 上下标：Unicode（H₂O、Fe³⁺、mol·L⁻¹、SO₄²⁻）。
- 反应符号：`⇌` `↑` `↓`。
- 反应条件：`=(点燃)=` `=(Δ)=` `=(高温)=` `=(煅烧)=` `=(通电)=`；条件箭头 `—H₂O→` `—加热浓缩→`。
- 分数线性化加括号：`(0.336L)/(22.4L/mol)`、`1mol:(1mol×4/3)=3:4`。
- 间隔号统一 `·`（如 `mol·L⁻¹`、`FeSO₄·7H₂O`）。
- **SUB/SUP 映射扫描**：转写前 grep 统计全部占位内容，对字典未覆盖字符（`—`、`＋`、`－`、空格等）逐一定义映射。
- 公式内全角 `＋`/`＝` → 半角；正文中文全角括号保留。

## 四 版式

1. 第 1 行标题：单空格，不用 `#`。
2. 殿干/【答案】/【解析】/【分析】/【点睛】/(1)(2)：普通段落，段间空行。
3. **题干选项行**（A．…、①—⑳）：`>` 引用块；连续选项合并同块，之间单独 `>` 分隔；【答案】/【解析】后不引用；**表格分支不得重置 in_q**（应对「题干→表格→选项」结构）。
4. 同行多选项：源 Tab 分隔 → 改单空格（与样板一致）。
5. 表格：管状表；合并单元格补空；首行表头与首列**仅总表加粗**，题目内表格不加粗。
6. 填空：保留多空格，不造下划线；填空框转双空格。
7. **块结构**：out 为块列表，块内 `'\n'` join，块间 `'\n\n'` join；表格行、引用块行不得被空行打散。

## 五 标准技术流程

1. **解包**：docx → `work/unpacked/`，记录 media 数、embeddings 数、_rels 映射。
2. **提取**：`extract_content.py` → `content_stream.txt`（`<P#|style>`、`<TBL n>…</TBL>`、` ||| `、`<MERGE>`、`[[OBJ:oleObjectN]]`、`[[DRAW:media/x.png]]`、`[[SUB:…]]`、`[[SUP:…]]`）。
3. **公式还原**：MTEF v5 解析器（`work/mtef/`）逐对象解析，**零剩余字节校验**；分批写 `formula_map.json`。DSMT6 变体要点：TMPL variation 固定 2 字节 LE、fence 无独立 tmpl_opt 字节；模板语义经预览图核验（27/28/29 ScrBox slots=[sub,sup]；0–9 fence 用 slot 括号字符；12 条件等号；23 lim 下标；隐形 2x1 矩阵='='；PUA U+EF02/EF04 隐形→空）。
4. **图片识别**：LibreOffice 批量 WMF→PNG，PIL 裁白边放大，md5 去重，分批识别，写 `figure_desc.md`（保留图描述 + 删除清单）。
5. **骨架**：`make_skeleton.py` 用映射零残留替换全部占位符生成 `skeleton.txt`。**while 循环铁律：所有 continue 前步进 i；表格分支消费 `</TBL>` 后 `i += 1`；out 为块列表**。
6. **转写**：以 skeleton.txt 为底逐行照抄成 md（不允许凭记忆改写），再按 figure_desc.md 插入图片与〔图〕描述；版式按第四节。
7. **复制图**：43 张保留图按原文件名复制到目标 `images/`，同名哈希比对跳过；**校验无游离媒体被误复制**。

## 六 审查

### 机审（脚本化，全部须通过）
- 占位符/内部标记零残留：`[[`、`⟨MISSING`、`⟨DESC?`、`<MERGE>`、`|||`、`<P`、`<TBL`、`</TBL>`、`oleObject`、`□`、`＋`、`＝`、`\t` 均为 0。
- 计数对应：题号数 == 【答案】数（题号分段重启属正常）；表格数与源一致。
- 图片引用：引用处数、唯一文件数、images/ 实际文件数三者一致；每处带 `〔图：…〕` 描述且非空；**media 中无引用的孤儿文件未复制**。
- 表格列数：每张表逐行列数一致。
- 全文逐行比对：skeleton 每行均为 md 子串（md 即 skeleton 时恒真）。
- 行尾离子电荷：grep 行尾 `Fe+`/`Fe2+`/`SO4`/`OH)` 等可疑模式，人工复核（多为假阳性）。
- **公式守恒**：标准校验器（系数×电荷、Unicode 上标转 ASCII、按 `+` 切项前 strip 空格）对全部可解析方程式做原子守恒+电荷守恒；碎片（被源文空格切断）人工复算。
- **空格三态审计**：公式符号旁无残余单空格；多空格填空与单位空格保留。

### 人工核
- 公式抽查守恒（重点：条件等号、配平、电荷）。
- 样板 md 版式对照。
- 保留图逐张复核描述。
- 修正项与保留项交叉核对（同物质多处排式一致）。
- 〔存疑〕汇总，迭代到无新问题。

## 九 历轮沉淀补充（2026-09-16 · 钠批次 10 件完成后并入）

> 本节把钠批次 10 件（含四件无「解析版」件）实测所得的**通用**结论并入本规范，四批共用。

1. **公式载体的四种形态**（开工先"三连判"）：① MathType OLE（`w:object>0` → MTEF 解析，须做逐对象字节零剩余 + WMF 预览交叉验证）；② Word 原生 OMML（`m:oMath>0`，条件等号是 `m:bar`/`m:limLow/Upp` 的线状槽）；③ EQ 域（`w:instrText>0`，段落级状态机，支持嵌套 `\o`）；④ **图片承载**（三判据全 0 时）——等号与条件等号做成小图，按"符号/公式图转文字"处理（`IMG_TEXT`：等号图→`=`、Δ 等号图→`=(Δ)=`），**不可判为"无公式"**。
2. **无「解析版」件的答案区三形态**：独立行`答案`／标题行「答案与分层梯度式解析」／独立标题行「参考答案」。统一按"含『答案』的短标题行＝答案区起点"处理，其后各行按普通段落输出、不进引用块；**某题无答案不得造答案**，在《转换说明》置顶项列出；`ANS_DIFF`（【答案】数−题号数）**允许为负**并写白名单理由（题号 N = 题干 a + 答案区 b）。
3. **子代理自动处理模式（S1–S8 由团队模式子代理执行）与上下文防护**：脚本输出 ≤200 行、禁读 >200 行文本、≥1000 px 大图禁用像素剖面工具（直接目验放大图）；`figure_desc.md` 边目验边落盘；成员自报"上下文将满"或停止响应时，主代理按**磁盘三查**（规则是否落盘／成品 md 行数·字符数是否与交付态一致／`stage_state.json` 是否含本轮键）判定断点后，派干净上下文新成员续做（复用 `work\` 产物，不重跑合格阶段），并在《转换说明》与台账断点记录如实披露。
4. **机审口径补充**：第 9/10 项扫描前须剔除 `〔图：…〕` 描述；第 10 项只匹配"恰好 1 个"空格（≥2 个属填空/答案字段分隔，保留），"系数后空格"须收窄 `(?=[A-Z](?![.．]))`；答案类标签须兼容 `【答案】`/`【参考答案】`；`normalize` 的公式字符类 `_F` 须含上标电荷符 `⁺⁻`（否则 `Cl⁻= 2NaCl` 类空格漏清）。
5. **四批工具库同步纪律**：通用脚本改动→先 U35 回归自测→回写钠批次→同步氯/硫/氮（MD5 四批一致）→各自归档记「工具库改动」；`docx_list.json` 属按批次文件，不跨批覆盖。
