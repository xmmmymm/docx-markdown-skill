|---|---|---|---|
| S1 解包 | docx → `work/unpacked/`（zip 解压）；统计 media/embeddings 数、导出 `document.xml.rels` | `work/unpacked/` | 目录齐全；rel 映射可读 |

## 四、转换规范速查（细则见 `..\转换规范（优化版）.md`）

1. **只提取正文**：不取页眉、页脚、批注、修订、超链接锚点；文本框内属于正文的题目内容**要保留**。
2. **公式优先程序化还原**：有 MathType OLE（MTEF 二进制）就直接解析，不做视觉识别；OLE/上下标图 → 转文字不插图。
3. **错误分级**：排版错误（下标排位、全角符号、残余空格、Tab）→ **修正并列出**；字样错误（KC1、HCI、1₂、源文配平错误）→ **原样保留并全部列出**；下标损坏 → **结合【答案】/【解析】及同文同物质正确排式反推修正并记录**。
4. **转写**：Unicode 上下标；`⇌ ↑ ↓`；条件等号 `=(Δ)=`/`=(点燃)=`/`=(高温)=`/`=(煅烧)=`；分数线性化 `(a)/(b)`；间隔号统一 `·`；根号 `√(…)`；公式内全角 `＋`/`＝`→半角（**正文中文全角括号保留**）。
5. **版式**：第 1 行标题（封面多行合并为一行、单空格、不用 `#`）；题干/`【答案】/【解析】/【分析】/【详解】/【点睛】`/小问均普通段落、段间空行；**题干选项行**（`A．…`、`①—⑳`，含 `a．`）用 `>` 引用块，连续选项合并同块、块内单独 `>` 分隔；**`【答案】…` 之后不再引用**（用 `in_ans` 状态机）；表格内选项保持表格；管状表，**仅总表**表头与首列加粗，题目内表格不加粗；合并单元格补空列/置空行；填空保留多空格，不造下划线；**块内 `\n`、块间 `\n\n`**。
6. **引用状态机**（勿用"选项正则无条件引用"）：标签行 `^【(答案|解析|分析|详解|点睛)】` → `in_ans=True`；题号行 `^\d+．` → `in_ans=False`；**表格分支不得重置 `in_q`/`in_ans`**。
7. **本批次已实证的新增条目（务必内置）**：
   - **EQ 域**：Word `eq \o(...)` / `eq \o\al(...)` 写在 `w:instrText` 且**跨多个 run**，必须在**段落级**用域状态机（begin/instrText/separate/end）还原；`\o\al(上,下)` → 下标槽在前、上标槽在后（`CO`+`\o\al(2－,3)` = `CO₃²⁻`）；主槽为等号时判条件等号 → `=(Δ)=`。
   - **`mc:AlternateContent`**：只取 `mc:Choice`，**必须跳过 `mc:Fallback`**，否则 WordArt 标题文字重复一遍。
   - **图形文本框**：`wps:txbx/w:txbxContent` 内的正文文字要取出（否则章节标题丢失）；但统计图形 `a:blip` 时**不得下探 `txbxContent`**（否则同图计两次）。
   - **游离空白 script run**：`vertAlign` 为 sub/sup 且文本仅空白且无对象占位 → 是域残留，**丢弃**。
   - **表格行切分**：行首/尾空白被清理后，用 `" ||| "` 切分会错位（空首格 → 行首空格被吃掉）→ **按裸 `|||` 切分再 strip**。
   - **浮动图（`wp:anchor`）位于题干段首**时，题号 `^\d+．` 会失配 → **行首连续图占位符先拆为独立图片块**，余下文本再按题号处理。

## 五、审查

### 机审（`audit.py`，**`FAILS: 无`** 方可交付）

1. 占位符/内部标记零残留（`⟨MISSING`、`⟨DESC?`、`<MERGE>`、`|||`、`oleObject`、`[[`、`□`、`\t`、`⟨FIG`、`＝`、`═`、`•`）；
2. 题号数 == `【答案】`数（题号分段重启属正常；源文自身重复标注 → 记白名单并说明）；
3. 表格数 == 源表格数，且每张表逐行列数一致；
4. 图片三一致（引用处数 = 唯一引用 = `images\` 文件数），每处带非空 `〔图：…〕`；
5. **内容保持**：md 与 skeleton 去格式后**字符多重集完全一致**（允许且仅允许 `fix_log` 中已记录的修正）；
6. 引用块结构：无 `> ` 紧跟 `> `（缺分隔）、无孤立 `>` 分隔行、引用选项行的上一非引用非空行不以 `【` 开头；
7. 行尾离子电荷复核（多为假阳性，逐条人工判）；
8. 方程式守恒（原子 + 电荷；**系数×电荷**、Unicode 上标先转 ASCII、按括号外 `+` 切项）；豁免项须逐条人工复核；
9. 空格三态（填空多空格保留、符号附近无单空格、词间单空格扫描）。

### 人工核

> **执行主体**（子代理自动处理模式）：本节与机审的**验收由主代理执行**；如需并行，可另派**只读**子代理分担（只读取 `work\figure_desc.md`、`work\audit_report.txt`、成品 md 与源图，**不给写权限**）。子代理版验收细则见第〇之二节第 5 条。

- 抽样 3 段与样板对照版式自洽；
- 保留图逐张对照源图复核 `〔图：…〕` 描述（装置连接/试剂/导管进出/加热方式；坐标轴量程与曲线关键值；流程节点与产物）；
- 公式抽查守恒（条件等号、配平、电荷、计算链自洽）；
- 修正项 vs 保留项交叉核对（同物质多处排式一致）；
- `〔存疑〕` 汇总，迭代到无新问题。

## 九、高频坑总表（开工前扫一眼）

**环境**
- venv：`<venv>\python.exe`（Windows 在 `Scripts/`）；禁用裸 `python`/`py`。
- WMF→PNG：LibreOffice headless `soffice --headless --convert-to png --outdir <目录> *.wmf`。
- 路径含空格/中文/U+3000，命令一律加引号；PowerShell 中 `$py` 变量须与命令同一次调用，或直接写全路径。
- 中文内容判定用 **Read 工具 / Python repr 落盘文件**，不看终端（GBK 会 `UnicodeEncodeError` / 乱码）。

**脚本**
- `while` 循环内任何 `continue` 前必须步进 `i`；表格分支消费 `</TBL>` 后 `i += 1`；表格分支不重置 `in_q`/`in_ans`。
- 块结构：`out` 为块列表，块内 `'\n'`、块间 `'\n\n'`（否则表格/引用块被打散）。
- `make_skeleton`/`make_md` 必须做**零残留校验**，不过即回炉。

**内容**
- 会"逻辑说不通"的 6 类高发错误：EQ 域丢失（缺上下标/缺条件等号）、`mc:Fallback` 重复文本、文本框文字丢失、游离空白 script、表格行错列、浮动图导致题号失配。
- SUB/SUP 字典扫描：`—→⁻`、`＋→⁺`、`－→⁻`、`−→⁻`；嵌套已转写字符映射自身。
- 下标损坏高发：`NaHCO3`/`Na2CO3`/`BaCO3`/`BaCl2`/`m1` → 结合同文正确排式修正。
- 游离 media（页眉页脚引用、OLE 的 WMF 预览、正文未引用）**不复制**；空白图须**像素级**判定才可删。
- 同图只识别一次描述，多处复用。
