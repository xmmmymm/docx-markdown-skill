## 三、字段口径

- **题号/答案**：`md 中 ^\d+． 的行数` / `【答案】出现次数`；两者不等时必须在备注写明白名单理由。
- **表格**：md 管状表数量，应等于源 `<TBL>` 数。
- **保留图/删除图/OLE**：`images\` 文件数 / 删除图数 / MathType OLE 对象数（"转文字图""OMML 数""同图复用"等其它形态写在备注）。
- **机审**：`work\audit_report.txt` 首行的结论（`PASS` / `FAILS: …`）。
- **执行模式**：`子代理自动处理`。团队模式子代理跑 S1–S8；主代理跑 S9–S10 并**独占回写**本文件、`_批次经验归档.md` 与 `_工具库\`；**子代理半途停止时主代理兜底接管**（照 U38 三查判定断点）。
- **回改件**：已交付件若事后回改（如序0 的 `＋`→`+`、序3 的图描述迭代、序4 的 `△`→`Δ`/删 ZWSP），须在备注登记「回改内容 + 处数 + 机审复跑结论」，并重跑 `audit.py` 使报告与成品一致。
