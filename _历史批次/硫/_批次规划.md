## 四、转换规范速查（细则见 `..\转换规范（优化版）.md`）

1. **只提取正文**：不取页眉、页脚、批注、修订、超链接锚点；文本框内属于正文的题目内容**要保留**。
2. **公式优先程序化还原**：有 MathType OLE（MTEF 二进制）就直接解析，不做视觉识别；OLE/上下标图 → 转文字不插图。
3. **错误分级**：排版错误 → **修正并列出**；字样错误（源文配平错误、漏字、`SO2`/`So2` 类笔误）→ **原样保留并全部列出**；下标损坏 → 结合【答案】/【解析】与同文正确排式**反推修正并记录**。
4. **转写**：Unicode 上下标；`⇌ ↑ ↓`；条件等号 `=(Δ)=`/`=(点燃)=`/`=(高温)=`/`=(催化剂)=`/`=(加热)=`；分数线性化 `(a)/(b)`；间隔号统一 `·`；根号 `√(…)`；公式内全角 `＋`/`＝`→半角（正文中文全角括号保留）。
5. **版式**：第 1 行标题（封面多行合并为一行、单空格、不用 `#`）；题干/`【答案】/【解析】/【分析】/【详解】/【点睛】`/小问均普通段落、段间空行；**题干选项行**（`A．…`、`①—⑳`）用 `>` 引用块，连续选项合并同块、块内单独 `>` 分隔；**`【答案】…` 之后不再引用**（`in_ans` 状态机）；表格内选项保持表格；管状表，**仅总表**表头与首列加粗；合并单元格补空列/置空行；填空保留多空格，不造下划线；**块内 `\n`、块间 `\n\n`**。
6. **引用状态机**：标签行 `^【(答案|解析|分析|详解|点睛)】` → `in_ans=True`；题号行 `^\d+．` → `in_ans=False`；**表格分支不得重置 `in_q`/`in_ans`**。
7. **上游已实证条目（继承自钠批次，务必内置）**：
   - **EQ 域**段落级状态机（`w:fldChar`+`w:instrText`，跨 run）；**嵌套 `\o`** 做槽位线状判定 + 嵌套递归；`\o\al(上,下)` → 下标槽在前、上标槽在后；主槽为等号 → `=(Δ)=`。
   - **`mc:AlternateContent`** 只取 `mc:Choice`，**跳过 `mc:Fallback`**。
   - **图形文本框** `wps:txbx/w:txbxContent` 内正文文字要取出；统计 `a:blip` 时**不下探** `txbxContent`。
   - **游离空白 script run**（`vertAlign` sub/sup 且文本仅空白、无对象占位）→ **丢弃**。
   - **表格行按裸 `|||` 切分再 strip**。
   - **浮动图位于题干段首** → 行首连续图占位符**先拆为独立图片块**。
   - **题号正则**统一 `^(\d+)\. *(?=[^\d\s])`（容忍"半角点+空格"，排除行首小数）。
   - **非 MathType 的 OLE 先查 `CompObj`**（如 `ACD/ChemSketch`，内部流 `\x01Ole10Native`）→ 按图处理，走 `render_ole_fig.py`。
   - **小 WMF 渲染全白 ≠ 空白图**：先跑 `dump_wmf2.py` 抽 MathML 实体。
   - **文末推广广告图**（`descr="promotion-pages"` + 前置分页符）→ 删除并写进《转换说明》置顶确认项。
   - **全角 `＋` 必须为 0**；交付前跑 `fix_fullwidth.py`。
   - **严禁用 `search_content`/`search_file` 判定零残留**（U27）。

## 五、审查

2. 题号数 == `【答案】`数（题号分段重启属正常；源文重复标注 → 记白名单并说明）；
3. 表格数 == 源表格数，且每张表逐行列数一致；
4. 图片三一致（引用处数 = 唯一引用 = `images\` 文件数），每处带非空 `〔图：…〕`；
5. **内容保持**：md 与 skeleton 去格式后**字符多重集完全一致**；

**环境**
