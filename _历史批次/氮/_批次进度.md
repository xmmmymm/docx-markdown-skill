## 三、字段口径

- **题号/答案**：`md 中 ^\d+[．、] 的行数` / `【答案】出现次数`；两者不等时必须在备注写明白名单理由（**ANS_DIFF 可正可负**：讲义体例为正、无标签件为负）。序0–5 为"答案/解析"类（已确认含题干），但**题号形态可能非典型**（顿号/空格/NBSP/`（多选）`前缀/讲义体例）：**S0 后先核实际形态**，按实际处理并写明白名单，**不要硬套 `^\d+．`**（U54/U57）。
- **表格**：md 管状表数量，应等于源 `<TBL>` 数；**列数以 Python 逐行复核为准**（`audit.py` 第 3 项打印值比实际大 1）。

- **载体形态·答案区形态**：S0 普查结论，按 U49 五形态 + U55 六形态填写（如 `OMML·独立行「答案」`、`图片承载·标准答案：`、`纯文本·【课时作业参考答案】`）。
- **机审**：`work\audit_report.txt` 首行的结论（`PASS` / `FAILS: …`）；**第 8 项须另附独立守恒复算**（`_工具库\_n_balance.py`，U63/U64），**0 处也要写明根因**。
- **执行模式**：`子代理自动处理`。团队模式子代理跑 S1–S8（内置 `code-explorer` 只读、不可用），主代理跑 S9–S10 并**独占回写**本文件、`_批次经验归档.md` 与 `_工具库\`。
