## 四、转换规范速查（细则见 `..\转换规范（优化版）.md`）

1. **只提取正文**：不取页眉、页脚、批注、修订、超链接锚点；文本框内属于正文的题目内容**要保留**。
2. **公式优先程序化还原**：有 MathType OLE（MTEF 二进制）就直接解析，不做视觉识别；OLE/上下标图 → 转文字不插图。
3. **错误分级**：排版错误（下标排位、全角符号、残余空格、Tab）→ **修正并列出**；字样错误（KC1、HCI、1₂、源文配平错误、漏字）→ **原样保留并全部列出**；下标损坏 → **结合【答案】/【解析】及同文同物质正确排式反推修正并记录**。
4. **转写**：Unicode 上下标；`⇌ ↑ ↓`；条件等号 `=(Δ)=`/`=(点燃)=`/`=(高温)=`/`=(煅烧)=`；分数线性化 `(a)/(b)`；间隔号统一 `·`；根号 `√(…)`；公式内全角 `＋`/`＝`→半角（**正文中文全角括号保留**）。
5. **版式**：第 1 行标题（封面多行合并为一行、单空格、不用 `#`）；题干/`【答案】/【解析】/【分析】/【详解】/【点睛】`/小问均普通段落、段间空行；**题干选项行**（`A．…`、`①—⑳`，含 `a．`）用 `>` 引用块，连续选项合并同块、块内单独 `>` 分隔；**`【答案】…` 之后不再引用**（用 `in_ans` 状态机）；表格内选项保持表格；管状表，**仅总表**表头与首列加粗，题目内表格不加粗；合并单元格补空列/置空行；填空保留多空格，不造下划线；**块内 `\n`、块间 `\n\n`**。
6. **引用状态机**（勿用"选项正则无条件引用"）：标签行 `^【(答案|解析|分析|详解|点睛)】` → `in_ans=True`；题号行 `^\d+．` → `in_ans=False`；**表格分支不得重置 `in_q`/`in_ans`**。
7. **上游已实证的新增条目（继承自钠批次，务必内置）**：
   - **EQ 域**：Word `eq \o(...)` / `eq \o\al(...)` 写在 `w:instrText` 且**跨多个 run**，必须在**段落级**用域状态机（begin/instrText/separate/end）还原；`\o\al(上,下)` → 下标槽在前、上标槽在后；主槽为等号时判条件等号 → `=(Δ)=`。**嵌套 `\o`**（外层叠条件、内层用两条 `\s\up/\s\do(_____)` 画线）要做**槽位线状判定 + 嵌套递归**，线状槽不得当作条件文字。
   - **`mc:AlternateContent`**：只取 `mc:Choice`，**必须跳过 `mc:Fallback`**，否则 WordArt 标题文字重复一遍。
   - **图形文本框**：`wps:txbx/w:txbxContent` 内的正文文字要取出；但统计图形 `a:blip` 时**不得下探 `txbxContent`**。
   - **游离空白 script run**：`vertAlign` 为 sub/sup 且文本仅空白且无对象占位 → 域残留，**丢弃**。
   - **表格行切分**：按裸 `|||` 切分再 strip，不要用 `" ||| "`。
   - **浮动图（`wp:anchor`）位于题干段首**时，题号 `^\d+．` 会失配 → **行首连续图占位符先拆为独立图片块**。
   - **题号正则容忍"半角点 + 空格"**：统一用 `^(\d+)\. *(?=[^\d\s])`（排除行首小数如 `2.3 g`）。
   - **非 MathType 的 OLE 先查 `CompObj`**（如 `ACD/ChemSketch`，内部流为 `\x01Ole10Native`）→ 按**图**处理，走 `render_ole_fig.py` 高分辨率重渲染。
   - **小 WMF 渲染全白 ≠ 空白图**：先跑 `dump_wmf2.py` 抽内嵌 MathML 实体（可能是被做成图的汉字）。
   - **文末推广广告图**：`<w:br w:type="page"/>` 之后、`wp:docPr descr="promotion-pages"` 的整页图 → 删除并写进《转换说明》「置顶确认项」。
   - **全角 `＋` 必须为 0**（规范 §六零残留清单含 `＋`）；交付前跑 `fix_fullwidth.py` 复核。
   - **严禁用 `search_content`/`search_file` 判定零残留**（含空格/中文路径静默返回 0，U27）。

## 九、高频坑总表（开工前扫一眼）

**环境**
- venv：`<venv>\python.exe`（Windows 在 `Scripts/`）；禁用裸 `python`/`py`。
- WMF→PNG：LibreOffice headless `soffice --headless --convert-to png --outdir <目录> *.wmf`（**outdir 须先存在**）。
- 路径含空格/中文，命令一律加引号；PowerShell 中 `$py` 变量须与命令同一次调用，或直接写全路径。
- 中文内容判定用 **Read 工具 / Python repr 落盘文件**，不看终端（GBK 会乱码/报错）。
- **子代理权限**：内置检索型子代理**只读**，S1–S8 必须派**团队模式**成员（U26）。
- **`search_content`/`search_file` 不可用于零残留判定**（U27）。

**脚本**
- `while` 循环内任何 `continue` 前必须步进 `i`；表格分支消费 `</TBL>` 后 `i += 1`；表格分支不重置 `in_q`/`in_ans`。
- 块结构：`out` 为块列表，块内 `'\n'`、块间 `'\n\n'`（否则表格/引用块被打散）。
- `make_skeleton`/`make_md` 必须做**零残留校验**，不过即回炉。
- 修正项计数**只计有效替换**（避免空操作虚高，U23）。

**内容（"逻辑说不通"6 类高发）**
- EQ 域丢失（缺上下标/缺条件等号）；`mc:Fallback` 重复文本；文本框文字丢失；游离空白 script；表格行错列；浮动图导致题号失配。
- SUB/SUP 字典扫描：`—→⁻`、`＋→⁺`、`－→⁻`、`−→⁻`；嵌套已转写字符映射自身。
- 下标损坏高发：`NaHCO3`/`Na2CO3`/`BaCO3`/`BaCl2`/`m1` 等 → 结合同文正确排式修正。
- 游离 media（页眉页脚引用、OLE 的 WMF 预览、正文未引用）**不复制**；空白图须**像素级**判定才可删。
- 同图只识别一次描述，多处复用。
- **氯批次特有提醒**：氯气相关题高发**实验装置图**（发生装置/除杂/干燥/收集/尾气处理、导管长短与进出）与**价-类二维图/转化关系图** → 保留图描述务必写到"导管进出方向、试剂、加热方式、坐标/轴标签、流程节点与产物"；`Cl₂`/`HClO`/`ClO⁻`/`ClO₃⁻` 等下标与电荷是**行尾丢字高发点**。
- **交付前零成本自检两条（U67，30 秒内可数完，却能拦住最严重的版式崩坏）**：① 成品 md 的 **`^>` 引用行数必须 > 0**（= 0 必是「题干题号与答案条目同形」误判）；② **题干区裸选项行必须 = 0**（含行内图的选项行尤其易漏，第 7 类高发）。
- **判"容器形状"必须放大再判（U34/U39 延伸）**：低分辨率缩略图会把**竖直直管看成圆形**（序6 `image6` 实测）；图描述抽验先用 `zoom_img.py`/PIL 裁剪放大，再下结论。
